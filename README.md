\# Infor Nexus — Cloud Computing \& SaaS Case Study



\## Overview



Academic case study exploring \*\*Infor Nexus\*\* as a cloud-based platform for global supply chain management.



The study examines how cloud computing enables connected supply-chain stakeholders, real-time visibility, coordination, and technology-driven decision support.



\## Key Areas



\- Cloud Computing in Global Supply Chain Management

\- Multi-Tenant SaaS Architecture

\- Enterprise Cloud Platforms

\- Real-Time Supply Chain Visibility

\- Cloud-Based Stakeholder Connectivity

\- AI-Enabled Predictive Insights

\- Operational Decision Support



\## Platform Studied



\*\*Infor Nexus\*\* — a cloud-based global supply chain platform connecting stakeholders such as brands, manufacturers, suppliers, logistics providers, retailers and financial institutions.

\*\*BCA — Cloud Computing Coursework\*\*  

Amrita School of Computing
